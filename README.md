\# Patient Management API (FastAPI)



\## 📌 Description

A simple backend API built using FastAPI to manage patient records stored in JSON format.



\## 🚀 Features

\- View all patients

\- View patient by ID

\- REST API structure

\- Auto-generated Swagger docs



\## 🛠 Tech Stack

\- Python

\- FastAPI

\- Uvicorn



\## ▶️ How To Run



1\. Create virtual environment:

&nbsp;  python -m venv myenv



2\. Activate:

&nbsp;  myenv\\Scripts\\activate



3\. Install dependencies:

&nbsp;  pip install -r requirements.txt



4\. Run server:

&nbsp;  uvicorn main:app --reload



Open in browser:

http://127.0.0.1:8000/docs
